# Public-source Portable PDB byte identity repair

**Implemented; candidate-feed unit tests pass. No package build or publication was performed.** Once the repository was authorized for public visibility, the byte audit exposed a host-dependent archive conversion: GitHub raw files and Git blobs are LF, but `git archive` honored this Windows installation's `core.autocrlf=true` and emitted CRLF for ordinary `.cs` files. The existing beta2 Portable PDB hashes therefore accurately matched its locally archived CRLF files, but did **not** match those SourceLink raw GitHub documents. Example `src/SpyBrowser.Cli/CommandLine.cs`: LF/raw/blob is 1,986 bytes with SHA-256 `a8797975aa3e49191f0149db1fb5b6bc51112c3d2c46dd166a487f25fdefb1b4`; CRLF archive is 2,047 bytes with SHA-256 `ee20f2376aa2574ac16e3f424bd376beb8461436619dde62edbfc6566b976cae`. It would be incorrect to normalize fetched remote source and label it byte-matching.

`tools/verification/build_candidate_feed.py` now routes archive creation through `archive_source_commit`, invoking `git -c core.autocrlf=false archive` for the resolved exact commit. `.gitattributes` adds `*.cs text eol=lf` to keep committed/check-out source bytes consistent on Windows and Linux. Existing license-text and numerical-fixture eol/hash rules were left unchanged. A regression test creates an isolated temporary Git repository with `core.autocrlf=true`, commits LF C# text, verifies default archive conversion to CRLF, and verifies the production helper archive equals `git show` blob bytes. Test scratch lives under workspace `.scratch` on `D:` and is automatically removed. No production C# semantics or dataset bytes changed.

The package version is now `0.2.0-beta.2.1`. This is a new immutable GitHub-only follow-up version, not permission to replace or relabel any beta2 tag, assets, or feed. Beta2's published checksum limitation remains; correction requires a new package cut from a new frozen source commit and independent parent verification that every source-controlled PDB checksum equals the corresponding raw GitHub bytes.
