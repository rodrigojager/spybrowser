The generated pin selects SDK 8.0.319 with roll-forward disabled. Prior standalone extraction/build/repack, license/payload inventory, 37-test result and 23-type IL comparison are supporting evidence only.
- **Metadata and CI dependency integration:** root `Directory.Build.props` enables SourceLink in CI and root `Directory.Packages.props` centrally pins `Microsoft.SourceLink.GitHub` 8.0.0. The added project reference is limited to CI when central package management is absent, with `PrivateAssets=All`; it avoids the prior duplicate centrally managed reference. `packaging-integration-review.md` records the observed pre-fix NU1504 and subsequent real CI restore pass. No runtime dependency is introduced by this build-only package reference; the current integrated source still needs its actual new-feed nuspec/runtime-dependency inspection.
- **SourceLink URI and document integrity:** the candidate builder independently derives the only accepted CDI mapping, `/_/*` → `https://raw.githubusercontent.com/rodrigojager/spybrowser/<full-40-character-SHA>/*`, requires exactly one matching CDI per PDB, checks normalized source-root paths and SHA-256 for each non-generated source document against the same archived source, and rejects incorrect caller expectations as well as incorrect CDI JSON. The older GitHub HTML route is rejected. Prior actual-PDB evidence reports 4 PDBs and 58/58 source-document checksum matches, but it is bound to 4d8a18c and does not substitute for the new feed audit. No remote URL fetch/accessibility is claimed.
- **Feed provenance and integrity guards:** the producer resolves the requested commit, archives that commit (rather than packaging dirty working-tree files), requires SDK 8.0.319, supplies explicit SourceLink JSON and deterministic path mapping, audits four expected package IDs/version/full repository commit/repository URL and four expected symbol packages/PDBs, checks duplicate PDB bytes and writes hashes into the manifest. A nonempty package output is rejected so an old feed cannot be relabeled; `--final` is opt-in, external publication remains false, and rights remain `UNVERIFIED`. It adds bounded command execution and limits termination to the owned command/process group/tree.
- **Docs and decision boundaries:** the package guide documents the pinned SDK, source/repack route, raw source revision inputs and boundaries; it preserves the no-publication/no-rights-clearance warning. Existing artifacts are expressly not evidence of an integrated final feed.
