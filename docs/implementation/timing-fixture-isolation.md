# Isolation of hard real-time test fixtures

The combined current Linux run retained in `artifacts/goal/linux-native-diagnostic-gap-merged-results/` passed 36 Cursory and 135/136 Playwright tests. The 180 ms fixed-cadence test inserted one character while its unchanged assertion required 2–12. This does not justify changing a native timeout, widening the prefix/time bounds, or deleting that assertion.

The fixture runs are now explicitly controlled: xUnit's `TimedInputCollection` disables unrelated test-class parallelism for the action/lifecycle and live missing-WebGL classes, and solution test commands use `-m:1` so the generator's thousands-of-call/concurrent numerical stress does not overlap those real-time browser fixture phases. Tests' **own** concurrent raw/wrapped actions, per-page parallel operations, and close races still run concurrently as written. No production budget, assertion, tolerance, pause, or retry was changed.

A first project-isolated Windows run still exposed the live missing-WebGL probe's unchanged ten-second deadline while other browser test classes ran concurrently. That failure is retained at `artifacts/goal/native-diagnostic-isolated-timing-results/`. Adding that test to the isolated collection (without disabling WebGPU or changing its hardware policy, probe timeout, or native flags) gave **36 + 136 passed, zero skipped** in `artifacts/goal/native-diagnostic-timed-probe-results/`. Linux project/fixture-isolated validation gave **36 + 136 passed, zero skipped** at `artifacts/goal/linux-native-diagnostic-isolated-timing-results/` before the missing-WebGL class received the same isolation annotation. These are separate, described execution conditions, not silent retries erasing the earlier failures.

CI now uses these project phases, explicitly provisions both the default stable Chrome identity channel and Playwright Chromium, and enables the actual foreground-focus assertion in the scheduled Linux headed lane. Disabled foreground-focus assertions report skips. CI uploads only test-result evidence; built NuGet archives remain job-local while dataset redistribution rights are unresolved, avoiding an artifact-upload bypass of the fail-closed release gate.

The hard scheduler/clock budgets retain deterministic fake-clock tests independent of this host scheduling. Shared-runner measurements remain observational; controlled-fixture success is not a claim of guaranteed native IPC latency on a saturated host.
