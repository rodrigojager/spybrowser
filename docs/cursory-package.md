# Cursory package build, demo, and corresponding source

`SpyBrowser.Cursory` is a standalone .NET 8 preview, licensed separately as
LGPL-3.0-or-later. Its DLL is not merged into SpyBrowser's MIT assemblies. The
pure library is independent of browser automation; `SpyBrowser.Playwright`
consumes it through an explicit, opt-in trajectory adapter. Package authors,
copyright and license metadata are explicitly scoped to this package.

## Reproduce and verify a local package

From the repository root, use the pinned .NET SDK 8.0.319. The package build
uses the actual .NET runtime framework version 8.0.22 and does not change the
trajectory implementation, compile-item projection, resource or defaults.

```powershell
$ErrorActionPreference = 'Stop'
$feed = Join-Path (Get-Location) 'artifacts/packages'
New-Item -ItemType Directory -Force $feed | Out-Null
dotnet restore src/SpyBrowser.Cursory/SpyBrowser.Cursory.csproj
dotnet pack src/SpyBrowser.Cursory/SpyBrowser.Cursory.csproj -c Release `
  -o $feed -p:ContinuousIntegrationBuild=true `
  -p:Version=0.2.0-beta.2.final.<source-short-sha> `
  -p:RepositoryCommit=<full-40-character-source-sha> `
  -p:SourceRevisionId=<full-40-character-source-sha> `
  -p:RepositoryUrl=https://github.com/rodrigojager/spybrowser.git
```

For reproducible correspondence, build from the exact clean commit being
identified. Pass the commit's full SHA as `RepositoryCommit`; do not hard-code a
revision into the project. CI builds enable SourceLink through a private,
build-only `Microsoft.SourceLink.GitHub` dependency. InformationalVersion carries
the source revision; deterministic path mapping uses
`/_/src/SpyBrowser.Cursory`. SourceLink and the portable PDB therefore describe
the source revision supplied to the build, rather than this documentation's
current checkout. A local build without CI can be used for ordinary development
but is not the source-linked release build.

The `.nupkg` includes the DLL, corresponding project/source and data, complete
licenses and notices, README, build guide and provenance manifest. The
`.snupkg` includes the portable PDB and source-link data. Verify each package's
SHA-256 against the manifest generated by the release verification process;
artifacts are not interchangeable when either hash or source commit differs.

## Pure NuGet consumer and no-sidecar check

`tools/Cursory.PackageDemo` references `SpyBrowser.Cursory` only by package ID
and version; it must not be changed to a `ProjectReference`. Its test runner
uses a NuGet config containing only the fresh local feed. It exercises
trajectory generation, endpoint/finite/time invariants, same-seed repeatability,
parallel calls, invalid-input rejection, embedded-resource SHA-256 and the
runtime dependency list. The consumer requires no Python, Node, browser, network
access or data generation.

On Windows run `tools/package-demo/verify.ps1`. It builds from the local feed,
then starts the consumer under a PATH restricted to the .NET host folder. The
harness checks process descendants and fails if the consumer starts a sidecar.
The proof is scoped to the consumer PID; save its captured output with the
package/hash manifest as validation evidence.

## Corresponding source, modifying, relinking and repacking

The package source is self-contained under `source/`: the standalone project,
all C# files, the exact `Data/trajectories.json.gz` and its manifest, README,
NOTICE, LGPL/GPL texts, third-party license texts, the pinned `global.json`,
and `BUILD-AND-MODIFY.md`. In particular the project-relative `LICENSE`,
`COPYING`, and `COPYING.LESSER` files are present alongside the extracted
project; do not attempt to rebuild from only `source/SpyBrowser.Cursory/` files
copied into an unrelated directory.

Extract the complete `source/` tree from the package, install the SDK version
specified by its `global.json` (exact SDK 8.0.319, roll-forward disabled).
Run commands from the extracted `source/` directory so that this pin applies:

```sh
dotnet --version  # must print 8.0.319
# cd source
dotnet build SpyBrowser.Cursory/SpyBrowser.Cursory.csproj -c Release
```

For a binary rebuilt outside the original Git checkout, pass its known full
revision explicitly when you need matching assembly version metadata, for
example `-p:Version=0.2.0-beta.2.final.<short-sha>` and
`-p:SourceRevisionId=<full-sha>`. A standalone extracted tree has no Git
metadata, so it cannot independently generate Git-derived SourceLink mappings;
source-linked release builds must be made from the corresponding Git checkout.

The extracted project has no references to the original repository, parent
`Directory.Build.props`, `Directory.Packages.props`, or production project
references. Its compile sources and embedded resource are the project's normal
SDK defaults and resource declaration. Edit the extracted C# sources to create
a modified library, rebuild, and relink the resulting
`SpyBrowser.Cursory/bin/Release/net8.0/SpyBrowser.Cursory.dll` with the
application (or pack the extracted project and update the package reference):

```sh
dotnet pack SpyBrowser.Cursory/SpyBrowser.Cursory.csproj -c Release -o ../modified-feed
```

Keep the DLL a separate assembly. The package does not promise support for
single-file, trimming, AOT or other bundling modes. This is a practical
corresponding-source and relinking path, not legal advice about every
distribution arrangement.

The algorithm source and recorded dataset are provided as matching
components; changing the gzip data requires updating the manifest and its
hash/counts and revalidating. The selected cursory-js snapshot has 2,356
records and omits recording id 2281 from the 2,357-record Python snapshot. No
human data is collected or added here.

## External distribution gate

The source algorithm notices are preserved, but independent rights and terms
for the SapiMouse / MouseSynthesizer recordings remain unverified. External
publication or redistribution of this package (especially the data) is blocked
until that provenance review is resolved. The authorship/rights status for
`Vinyzu`, Jake Writer and SpyBrowser is not independently verified by this
build work. Do not infer clearance from the upstream project's statement. This
package work does not claim legal approval.
