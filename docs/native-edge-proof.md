# Native edge and fault contract test evidence

This supplement adds adversarial checks without changing the runtime contract or reference fixtures.

## Assertions added

- `tests/SpyBrowser.Tests/NativeFaultContractTests.cs` loads a byte-modified copy of the actual unsigned `SpyBrowser.Cursory` PE into a collectible load context. One case mutates the embedded gzip payload (valid PE, invalid dataset SHA-256); the other mutates the embedded resource name (valid PE, missing resource). Both invoke the isolated public generator and require `InvalidDataException` rather than a returned trajectory. This exercises the shipped resource-loading path without production injection hooks or changing fixture tolerance.
- The same file tests repeated deterministic transport pauses against the real monotonic scheduler, verifies coalescing and final endpoint delivery, and verifies that a transport exception is rethrown as the same exception instance, no confirmation occurs for the failed sample, and no endpoint/future sends follow.
- `tests/SpyBrowser.Cursory.Tests/GeneratorEdgeContractTests.cs` covers four directional quadrants, horizontal/vertical and negative fractional coordinates, subpixel endpoints, stationary no-op, finite monotonic output, `UInt128.MaxValue`, the implemented frequency/randomizer/directness bounds, and mutation attempts against returned point/time collections.

These tests intentionally do not assert private expected vectors generated by .NET. Existing parity fixture tolerance remains unchanged. Dataset corruption is validated at the standalone generator boundary; it does not instrument a second wrapper/Playwright load context or claim a browser dispatch occurred.
