# SpyBrowser.Cursory (experimental native generator)

Standalone .NET 8 library for generating recorded mouse trajectories. The
separately linked SpyBrowser.Playwright integration can select this generator
explicitly with `MouseTrajectoryAlgorithm.Cursory`; Bézier remains the default.
The library itself has no Playwright dependency.

```csharp
using SpyBrowser.Cursory;
var trajectory = CursoryTrajectoryGenerator.Generate(
    new TrajectoryPoint(20, 30), new TrajectoryPoint(500, 280),
    new TrajectoryOptions { Seed = 42, Frequency = 60 });
for (var i = 0; i < trajectory.Points.Count; i++)
    Console.WriteLine($"{trajectory.Timings[i]} ms: {trajectory.Points[i]}");
```

The DLL has no runtime dependency other than the .NET 8 BCL and carries a
compressed recording dataset. RNG state is per generation; the dataset is
validated and loaded once. The differential suite matches 160 pinned
cursory-js trajectory cases at `1e-9` absolute pixel tolerance plus exact
PCG64 and distribution vectors. This is fixture-scoped evidence, not exhaustive
parity.

The package contains matching corresponding C# source, embedded dataset,
